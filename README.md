# odoo-free-modules

Modul Odoo gratis (Odoo 20 Community).

| Modul | Fungsi |
|---|---|
| `casa_list_header_tooltip` | Hover di header kolom list menampilkan field-nya seperti di Odoo 18, termasuk grup kolom (Description, Quantity, Amount di baris Sales Order). Mode debug menampilkan nama teknis field. |
| `casa_sale_totals_tooltip` | Hover di blok total Sales Order/Invoice (Untaxed Amount, baris pajak, Total, Margin) menampilkan field di baliknya. Mode debug menampilkan nama teknis dan ekspresi untuk template report. Butuh modul Sales. |

## Pasang

Tambahkan folder ini ke `addons_path` Odoo, update daftar Apps, lalu install modulnya.
